# PixelGnome v0.31.2 — Release Notes

**Date:** 2026-10-08
**Type:** Patch — display fix.
**Against:** v0.31.1

## Fixed

### SVG card original dimensions (LAB-173 follow-up)

Found during the v0.31.1 live check. A percentage-sized SVG (`width="100%" height="100%" viewBox="0 0 640 320"`) showed **300 × 150** as its original dimensions on the preview card while exporting at the correct 640 × 320.

Cause: `getImageDimensions()` in `src/modules/preview.js` loaded the raw file into an `<img>` and read `naturalWidth/naturalHeight`; Chrome falls back to its 300 × 150 default for percentage-sized SVGs.

Fix: for SVG input, `getImageDimensions()` now uses `rasterizeSvg()`'s parsed `_svgWidth/_svgHeight` — the same size the export path uses — so the card's "before" and "after" agree. Non-SVG files are unchanged. Verified in Chromium: mm, inch, percent and negative-viewBox SVGs all show matching original/output dimensions.

Export output is unaffected (it was already correct in v0.31.1).
