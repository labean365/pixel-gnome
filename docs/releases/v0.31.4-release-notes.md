# PixelGnome v0.31.4 — Release Notes

**Date:** 2026-10-08
**Type:** Patch — i18n fix (LAB-28).
**Against:** v0.31.3

## Headline

Switching the UI language mid-session now updates everything already on screen. Before, cards for files you'd already added stayed in the old language (and old number format) until you re-added them.

## Fixed

- **Preview cards (image + PDF) re-translate in place.** No reprocessing, no thumbnail regeneration.
  - *Static text* — stat labels, button labels, tooltips (`data-tooltip`), `title`, `aria-label`, `alt`, badges — now carries `data-i18n` / `data-i18n-attr` markers, re-applied by `applyStaticTranslations()` on a switch. New `data-i18n-vars` (JSON) supplies interpolation vars such as the file name or frame count.
  - *Computed values* — file sizes, decimal ratios, savings rows (Saved / Larger / Rasterized), PDF "N pages · size" lines and the processed-card aria-label — are re-rendered by new `relocalizePreviewCards()` from raw numbers stored on each element (`data-bytes`, `data-ratio`, `data-savings`, …).
- **Step 3 export readout** was hard-coded English in every locale ("2 images · ~1.11 MB out"). Now translated ("2 immagini · ~1,11 MB in uscita") and refreshed on a switch.
- **Image card screen-reader labels** ("Image: … processing" / "Image processed: …") were hard-coded English. Now translated.
- **Also refreshed on a switch:** preset dropdown ratio badges ("1,90:1"), History panel (heading, clear button, row sizes and times), full-window drop overlay.

## Verification (Chromium)

Snapshot of every card's text plus `title` / `aria-label` / `data-tooltip` / `alt` attributes, with an SVG, a JPG, an animated GIF and a 4-page PDF loaded:

| Scenario | Differences |
|---|---|
| EN → IT switch vs. same files loaded fresh in IT | 0 |
| IT → EN switch back vs. original EN | 0 |
| Switch to IT *while files are still processing* vs. fresh IT | 0 |

Outside the cards, the only remaining old-language text after a switch is the last screen-reader announcement (a past live-region message — intentionally not re-announced). EN and IT dictionaries at parity (531 keys).

## Known gap (not in this release)

Built-in **preset names** ("Full HD", "Social Square", …) and their dropdown group labels are English in every language — they were never in the dictionaries. Logged as a follow-up.
