# PixelGnome v0.31.5 — Release Notes

**Date:** 2026-10-08
**Type:** Patch — maintenance only, no user-facing changes.
**Against:** v0.31.4

## Changed

### Build tools (supersedes Dependabot's dev-dependencies PR)

| Package | Before | After |
|---|---|---|
| vite | 8.0.16 | 8.3.4 |
| eslint | 10.5.0 | 10.12.0 |
| prettier | 3.8.4 | 3.9.9 |
| globals | 17.5.0 | 17.13.0 |

Dependabot's July PR proposed vite 8.1.3 / eslint 10.6 / prettier 3.9.4 / globals 17.7; these are the current releases within the same majors. `npm audit fix` (non-breaking) also cleared the high-severity `brace-expansion` advisories. Remaining: `braces` via `vite-plugin-singlefile` → `micromatch` — dev/build-time only, never shipped, and the only "fix" npm offers is a breaking downgrade of the plugin, so it's left as is (it was present before this release too).

**Built output compared before/after:** same set of assets with near-identical sizes (main bundle +11 bytes). The one structural change is Vite's shared runtime chunk being renamed `chunk-*.js` → `rolldown-runtime-*.js`. Prettier 3.9 reformatted nothing; lint still 0 errors.

### Deploy gate + setup-node (supersedes Dependabot's actions PR)

`pixel-gnome-build.yaml` (the IONOS Deploy Now build):

- New **Verify PDF engine** step runs `scripts/check-pdf-engine.mjs` after the build-contract check, so a MuPDF update that breaks PDF saving (as 1.28 would have in v0.31.3) fails the deploy instead of shipping.
- `actions/setup-node` v6 → v7.

Note: Deploy Now's build only runs for pushes to `main`, so this gates deploys; it does not run on pull requests.

### Dependabot config

Removed the `labels:` entries from `.github/dependabot.yml`. The `dependencies` and `github-actions` labels don't exist in the repo, which made every Dependabot PR show a configuration error.

### Misc

`vite.singlefile.config.js` uses `import.meta.dirname` instead of `__dirname`, silencing Vite 8.3's warning about the upcoming native config loader. The inlined favicon in the single-file build is unchanged.

## Testing

- `npm run verify` green (lint, format, build:all, check:pdf, check:pdf-engine).
- Dev server: SVG sizing harness (17 fixtures × 3 settings), language-switch test (0 differences in all three scenarios), PDF worker test (all operations, identical sizes to v0.31.3).
- Production build via `vite preview`: PDF, JPG, SVG and animated-GIF cards process correctly; no page errors.
