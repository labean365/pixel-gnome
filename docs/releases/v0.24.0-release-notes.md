# PixelGnome v0.24.0 — Release Notes

**Date:** 2026-06-19
**Type:** Stable — major feature (PDF toolkit). First release to drop the `-rc` label.
**Against:** v0.24.0-rc (promotes it to stable) / v0.23.0-rc

## Headline

PixelGnome graduates to a **stable 0.24.0** and ships a complete, **client-side PDF toolkit** — compress, organize, merge, and convert PDFs entirely in the browser, with the same no-upload privacy promise as the image tools. A multi-MB MuPDF (WebAssembly) engine loads lazily on first PDF use and runs in a dedicated Web Worker.

## PDF toolkit

- **Compress / Optimize** — structural optimization (recompress embedded images, strip metadata, subset fonts, garbage-collect) that **preserves selectable text and vectors** (never rasterized). Presets + Advanced controls, multi-page preview, before/after size readout.
- **Organize** — extract / remove / split pages from a page-thumbnail grid; split by every-page or custom ranges (e.g. `1-3, 5, 8-10`) into a ZIP.
- **Merge** — combine multiple PDFs with a reorderable list; dropping several PDFs opens Merge preloaded.
- **Images → PDF** — combine processed images into one PDF (one page per image) from the export bar.
- **PDF → images** — rasterize pages to PNG/JPEG at Screen (96) / Standard (150) / Print (300 DPI); download a ZIP or send pages into the editor queue.
- Italian translations for all PDF strings; content-free, consent-gated analytics (`pdf_optimized` / `pdf_organized` / `pdf_merged` / `pdf_rasterized`).
