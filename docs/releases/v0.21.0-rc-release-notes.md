# PixelGnome v0.21.0-rc — Release Notes

**Date:** 2026-06-07
**Type:** Release candidate — feature (internationalization)
**Against:** v0.20.0-rc
**Plan:** `docs/i18n-Plan-2026-06.md` · **Native review:** `docs/i18n-Italian-Review.md` · **Deploy:** `docs/releases/v0.21.0-rc-deploy-IONOS.md`

## Headline

PixelGnome is now **bilingual (English + Italian)**, switchable from a new **globe-icon dropdown** in the header. First-time visitors are auto-detected from their browser language; the choice is then remembered locally. The translation is a careful draft pending a native-speaker review.

## What's new

**Framework-free i18n layer.** A ~50-line runtime (`src/modules/i18n.js`) provides `t(key, vars)` with `{placeholder}` interpolation, `{one/other}` pluralization, and English fallback for any missing key. Strings live in plain dictionaries — `src/locales/en.js` (source of truth) and `src/locales/it.js` — bundled at build time so the portable single-file build stays self-contained and offline. Adding a future language is "drop in `locales/<code>.js` + two lines in `i18n.js`."

**No flash of the wrong language.** A small inline `<head>` script resolves the locale and sets `<html lang>` before first paint. It lives outside the analytics markers, so it survives the single-file build's strip step.

**How strings are wired.** Static markup carries `data-i18n` / `data-i18n-attr` / `data-i18n-html` hooks scanned on load, with English text retained inline as the SEO default. Dynamic strings — toasts, screen-reader announcements, and JS-built templates — call `t()` directly.

**Globe-icon switcher.** New header control (English / Italiano), keyboard- and screen-reader-accessible, with the active language checkmarked.

## Coverage

Translated and live: the entire main screen and resize → export workflow (`main.js`, `settings.js`, `preview.js`), the crop / image editor (`crop-modal.js`, `crop-colors.js`), and the Help, Privacy, cookie-consent, and History surfaces. 351 i18n keys at full EN/IT parity.

**Intentionally English:** the Changelog entries (a dated historical dev record); the changelog *tab label* itself is translated.

## Scope / non-goals

- **SEO stays English-focused.** This is a client-side toggle only. Per-locale `/it/` URLs + `hreflang` are a deferred, no-rework follow-up — the dictionaries already exist.
- **Italian is a draft** pending native review (`docs/i18n-Italian-Review.md`).
- Minor cosmetic: a few Italian button labels run longer than their English counterparts — acceptable, no layout breakage observed.

## Known limitation

Switching language mid-session re-translates the static chrome and any modal opened afterward, but preview cards already on screen keep their original-language labels until reprocessed. First-load detection (the common case) is fully correct.

## Verification

- `eslint .` → 0 errors (pre-existing warnings only).
- Multi-file and single-file production builds both pass; footer reads **v0.21.0-rc**; Italian confirmed bundled in both.
