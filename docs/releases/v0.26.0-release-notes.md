# PixelGnome v0.26.0 — Release Notes

**Date:** 2026-06-20
**Type:** Stable — feature (Tier C, C3 Recipes).
**Against:** v0.25.0

## Headline

Step 2 now leads with **"What do you want to do?"** — a row of one-tap **recipes** above the size presets, making the task the front door instead of the dimensions. This is the C3 slice of the unified file-utility direction. It's **image-first**: recipes drive the image pipeline now, and PDFs pick up the matching defaults when you act on them; the cross-type export behavior is C4.

## Added

- **Recipes row in Step 2**, three intents that each apply sensible defaults and surface the relevant controls:
  - **Compress / optimize** — keep the original dimensions, just shrink (applies the "Original size — convert & compress" preset).
  - **Make email-safe** — resize small and widely-compatible (max long edge 1600 px, JPEG, quality 75, metadata stripped).
  - **Convert format** — change the format without resizing; opens Customize and focuses the format picker.
- The chosen recipe stays highlighted and **clears automatically** when you pick a preset or change any setting by hand (the settings no longer match the intent). The size presets and Customize panel are unchanged beneath it.
- Content-free **`recipe_selected`** analytics event (records only which recipe was chosen — no file data). Italian translations for all recipe strings.

## Implementation

- `src/modules/settings.js` — `RECIPES` map + `applyRecipe()` / `renderRecipeActive()`; `state.recipeId` carried through `applyPresetToState` / `fillSettingsDefaults`; `switchToCustom()` clears the active recipe on manual edits.
- `src/index.html` — `.recipe-row` chip group above `#presetSelect`.
- `src/style.css` — `.recipe-chip` styling (accent-tint hover, accent active).
- `src/locales/en.js`, `src/locales/it.js` — `recipe.*` strings.
- `src/modules/analytics.js` — `trackRecipeSelected`.
