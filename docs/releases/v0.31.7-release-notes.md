# PixelGnome v0.31.7 — Release Notes

**Date:** 2026-10-17
**Type:** Patch — i18n fix (LAB-484) + two dependency updates (supersedes Dependabot PRs #11 and #12).
**Against:** v0.31.6

## Fixed — preset dropdown follows the UI language (LAB-484)

Italian strings for every built-in preset and group already existed in `it.js` (used by the static `<select>` in `index.html`), but `rebuildPresetDropdown()` replaced the options at startup using the hard-coded English `name` / `group` fields from `presets.js`, so the list was always English.

- `presets.js`: each built-in gets a `nameKey` (`preset.fullHd`, …). New `getPresetDisplayName(preset)` returns `t(nameKey)` for built-ins and the typed `name` for user presets. `name` stays as the English fallback and for `isValidPreset`.
- `settings.js`: option text uses `getPresetDisplayName()`; optgroup labels come from `preset.groupOriginal / groupWeb / groupSocial / groupEmail / groupSaved`. `rebuildPresetDropdown()` already re-runs on a locale change (LAB-28), so a live switch updates the list.
- The `prompt('Preset name:')` and the overwrite / delete `confirm()` texts were English-only; now `preset.namePrompt`, `preset.overwriteConfirm`, `preset.deleteConfirm`.
- Locale strings: removed the hard-coded ` · 1:1`-style suffixes (the dropdown appends the badge via `getPresetRatioBadge()`), so the decimal badge localizes (`1,90:1` in Italian). New keys: `preset.original`, `groupOriginal`, `groupSaved`, `namePrompt`, `overwriteConfirm`, `deleteConfirm`.

New IT strings (drafts for LAB-24): *Dimensione originale — converti e comprimi*, *Originale*, *Preset salvati*, *Nome del preset:*, *Esiste già un preset chiamato "{name}". Sovrascriverlo?*, *Eliminare il preset "{name}"?*
