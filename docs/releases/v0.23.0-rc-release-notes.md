# PixelGnome v0.23.0-rc — Release Notes

**Date:** 2026-06-16
**Type:** Release candidate — infrastructure / CI + perf + one editor fix
**Against:** v0.22.0-rc
**Deploy:** Automatic on push to `main` — no manual deploy guide needed (see below)

## Headline

A maintenance release that moves PixelGnome onto **continuous deployment** and clears the last two backlog items. The core image workflow is unchanged; there's one visible editor fix.

## What's new

**Continuous deployment.** pixelgnome.com now builds and deploys automatically from the GitHub repo (`github.com/labean365/pixel-gnome`) on every push to `main`: GitHub Actions runs `npm ci` → `npm run build` → publishes `dist/`. This replaces the previous manual `dist/` upload. `README.md` has a **Deployment** section describing the flow.

**Editor toolbars wrap at tight widths.** The crop editor's Aspect Ratio / Quick Crop / Export Size toolbars used to scroll horizontally on narrow windows, hiding controls behind a scrollbar. They now wrap onto extra rows instead. No change on wide screens — wrapping only engages when a row doesn't fit.

**Cache-control headers.** A new `public/.htaccess` sends `Cache-Control: no-cache, must-revalidate` on the HTML entry point (so a new deploy reaches returning visitors immediately, no hard refresh) while content-hashed JS/CSS get a one-year `immutable` cache; images get a day, `robots.txt`/`sitemap.xml` an hour. Previously no explicit cache headers were sent.

## Fixes

**`build:single` version check repaired.** The single-file post-build validator (`scripts/cleanup-singlefile.mjs`) looked for the old `#versionBadge` id (renamed to `#footerVersion` in v0.19), so `build:single` / `build:all` always exited 1. It now targets `#footerVersion`.

**CI install + dependency conflict.** The generated build workflow had no install step (`vite: not found`) — added `npm ci` + npm caching. That surfaced a pre-existing peer conflict (`@eslint/js@^10` vs `eslint@9`), fixed by pinning `@eslint/js` to `^9` (→ 9.39.4) and regenerating the lockfile, so the install runs clean without `--legacy-peer-deps`.

## Housekeeping

- `.prettierignore` extended to skip the generated Deploy Now workflows, `deploy-*/`, and throwaway mockups; source files run through Prettier.
- Removed stale local build-artifact folders (`deploy-v0.21.0-rc/`, `deploy-v0.22.0-rc/`, `dist/`, `dist-single/`).
- GitHub repo created and commit history normalized to the GitHub noreply identity.

## Scope / non-goals

- **No change to the image workflow** — presets, resize modes, convert & compress, and the export path are untouched.
- **Italian remains a draft** pending native review (unchanged this release).

## Verification

- `eslint .` → 0 errors (pre-existing warnings only).
- `npm run build:single` passes; the version check now reports "version badge matches package.json (v0.23.0-rc)".
- Live + staging serve v0.23.0-rc over Deploy Now; HTML returns `Cache-Control: no-cache`, hashed assets `immutable`.
- Crop editor toolbars wrap (no horizontal scrollbar) at narrow widths; single line preserved on desktop.
