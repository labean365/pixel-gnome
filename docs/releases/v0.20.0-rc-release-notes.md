# PixelGnome v0.20.0-rc — Mobile & Small-Window Responsiveness

> **Release candidate.** Feedback-gated before promoting to v0.20.0 stable. Headline work is the mobile/tablet responsiveness pass specified in [`docs/Mobile-Responsiveness-Plan.md`](../Mobile-Responsiveness-Plan.md); this release also rolls up the previously-unreleased Customize two-column layout, landing-state tuning, and header changes (see [CHANGELOG](../../CHANGELOG.md)).

## Highlights

The app is now genuinely usable on phones and in narrow desktop windows, with the desktop layout left untouched. All responsiveness changes are CSS-only and scoped to breakpoints (or no-ops on desktop), so there are no behavioral or markup changes for existing wide-screen users.

- **Phones get the full sizing controls back.** The stacked sidebar no longer crushes "Choose a size" into a tiny scroll sliver.
- **One Download area on phones**, bigger touch targets, and crop toolbars that show there's more to scroll.
- **Tablets / narrow windows no longer clip card stats.**
- **No more layout jumps** when a mobile browser's address bar shows/hides (`dvh`).

## Mobile responsiveness (the three-phase plan)

### Phase 1 — Phones (≤ 768px)

- **Sidebar no longer crushed.** The stacked sidebar was capped at `max-height: 40vh` with `overflow: hidden`, squeezing the inner `.settings-scroll` (preset selector, Save Preset, the Customize size/format/quality accordion — ~228px of content) down to ~32px. The cap and inner scroller are removed on phones; the page now scrolls as one natural column so every control is reachable. Desktop keeps its pinned drop-zone / scrolling-middle / pinned-Export sidebar.
- **De-duplicated Download.** The redundant sidebar **Step 3 · Export** cluster (Download / ZIP) is hidden ≤768px; the Preview toolbar already carries Download / Download ZIP / Responsive ZIP plus selection, so there's a single, unambiguous export area.
- **44px touch targets.** Header, preset-row (delete/export/import), and per-card action icon buttons hit the ~44px touch guideline on phones.
- **Discoverable crop toolbars.** The horizontally-scrolling Aspect Ratio / Quick Crop / Export Size rows show a soft edge scroll-shadow so off-screen presets are no longer hidden on touch.

### Phase 2 — Tablets / narrow windows (769–900px)

- **Card stats stop clipping.** In the narrow two-column band the fixed `320px` card thumbnail squeezed the stats column until the Dimensions / Size / Saved values clipped off the right edge. The thumbnail is now fluid (`clamp(160px, 34%, 320px)`, `aspect-ratio: 4 / 3`) in this band; desktop (≥901px) keeps the fixed 320px thumb and the two-column tablet layout is preserved.

### Phase 3 — Dynamic viewport height

- **`dvh` with `vh` fallback** on `body` / `#app` `min-height`, the empty-state hero padding, and the Help modal `max-height`, so showing/hiding a mobile address bar doesn't shift the layout. `dvh` equals `vh` without dynamic browser chrome, so desktop is unchanged.

## Also in this release (rolled up from [Unreleased])

- **Customize panel — two-column "inline grid" layout** on desktop (≥960px, gated on `has-images`), with Format + Quality paired on one row.
- **Landing state tuned for laptops & short screens** — drop-target max-height caps and a top-aligned canvas hero.
- **Header slimmed; tagline back inline.**
- **Customize disclosure starts collapsed every load.**

See the [CHANGELOG](../../CHANGELOG.md) for full detail on these.

## Verification

Audited on the live site at true CSS widths via a same-origin iframe (media queries evaluate against the iframe width, since window resizing didn't change this browser's viewport). Measured results on the branch build:

- Phone (390px): the "Choose a size" scroll region went from **32px → full height** (no content hidden); icon buttons measured 44×44; Export cluster `display:none`; crop toolbar shows a 4-layer scroll-shadow.
- Tablet (820px): card stats went from **+57px clipped** (overflowing the content edge) to **−32px clearance** (inside); thumbnail fluid at 160px; layout stays two-column.
- Desktop (1100px): card thumbnail unchanged at **320px**.

## Risk

Low. CSS-only, breakpoint-scoped, no JS or markup changes. Desktop layout unaffected.
