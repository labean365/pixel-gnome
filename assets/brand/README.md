# Brand assets

Source artwork for the PixelGnome mascot/logo.

- **`pixel-gnome-head.png`** — **active logo source.** The header logo, favicons, apple-touch icon, and OG image are all derived from this file (see `public/` for the generated raster icons and `src/favicon.svg` / `src/index.html` for the inline data-URI versions).
- `pixel-gnome.png`, `pixel-gnome-white.png`, `pixel-gnome-small.png` — alternate / full-body mascot variants, kept for future use (site mascot, marketing, etc.). Not currently referenced by the app.

Obsolete pre-rebrand logo files (`PixelDrop-Logo.*`) live in `../_archive/`.
